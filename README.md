# NightRoad Guardian — Frontend v1

A responsive HTML/CSS/JavaScript frontend prototype.

## Run locally
1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` with VS Code Live Server (recommended), or open it in a browser.
4. For camera and location, use localhost/HTTPS and allow browser permissions.

## Included interactions
- Responsive navigation
- Image upload and preview
- Camera open/capture (browser permission required)
- Geolocation permission request
- Local demo report entries
- Honest placeholder for AI analysis

## Important
This is the **frontend prototype**. It does not perform real pothole AI detection or send reports to a server yet. To enable that, connect `app.js` to the Python FastAPI backend and configure a compatible pothole-trained model.
